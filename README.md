# AI in Music Scoring

The music industry is changing fast. More and more AI tools are used to create songs, from lyrics and voice to arrangement, mixing, and even complete tracks.

This simple online scoring tool helps estimate how much AI was involved in a final musical work.  
Users can check the parts created with AI, see the score instantly, and generate an image with the result.

That image can be shared with listeners to make the level of AI involvement clear and transparent.
