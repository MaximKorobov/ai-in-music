# Puntuación de IA en música

La industria musical está cambiando rápido. Cada vez se usan más herramientas de IA para crear canciones, desde la letra y la voz hasta el arreglo, la mezcla, el mastering e incluso pistas completas.

Este sencillo evaluador en línea ayuda a estimar cuánto participó la IA en una obra musical final.  
El usuario marca las partes creadas con IA, ve la puntuación al instante y puede generar una imagen con el resultado.

Esa imagen se puede compartir con la audiencia para hacer transparente el nivel de participación de la IA.
