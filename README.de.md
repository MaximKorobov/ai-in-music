# KI in der Musik Bewertung

Die Musikindustrie verändert sich schnell. Immer mehr KI-Tools werden zur Songproduktion eingesetzt: von Text und Stimme über Arrangement, Mixing und Mastering bis hin zu kompletten Tracks.

Dieses einfache Online-Tool hilft dabei einzuschätzen, wie stark KI an einem fertigen Musikwerk beteiligt war.  
Nutzer markieren die mit KI erstellten Teile, sehen die Bewertung sofort und können ein Bild mit dem Ergebnis erzeugen.

Dieses Bild kann mit dem Publikum geteilt werden, um den KI-Anteil transparent zu machen.
